### 🚀 Featured Work

**🎓 [Bachelor's Thesis: User-Space Device Drivers on Embedded Linux, C vs Rust](https://github.com/SilasHofer/C-and-Rust-driver)** *(Grade: A)*
An empirical comparison of two functionally equivalent user-space drivers for a BME280 sensor, one in C and one in Rust, on a Raspberry Pi 3B. We evaluated reliability with a 48-hour stress test, memory safety with Valgrind, fault handling with LD_PRELOAD fault injection and 12 hours of AFL++ fuzzing, architectural complexity, and performance. Both drivers were stable with no crashes or leaks. Rust gave more consistent error handling, at the cost of slightly higher memory use and code complexity.
*Co-authored. I wrote the Rust driver and the Python test infrastructure, and did the SPRT statistical analysis.*
`Rust` `C` `Embedded Linux` `I2C` `Fuzzing` `Python` `SPRT` · [Read the thesis](https://urn.kb.se/resolve?urn=urn:nbn:se:bth-29775)

**💡 [Magic Home Control](https://github.com/SilasHofer/MagicHomePC)**
A local controller for Flux LED smart bulbs. It has a FastAPI REST backend, an Angular web UI, and a Tkinter system-tray app, and all three share one SQLite database. It finds bulbs on the network with UDP broadcast, runs with Docker Compose, and includes tests.
`Python` `FastAPI` `REST API` `SQLite` `Angular` `Docker` `Linux`

**🖥️ [Visual Control System for Connectitude](https://github.com/SilasHofer/connectitude-board)**
A fullstack web app for large touchscreen displays used in industrial meetings. It has configurable board layouts, production-data widgets and attendance tracking, integrates with Connectitude's API, and runs in Docker.
*I built the backend, the production-data widgets and the API integrations.*
`C#` `.NET Web API` `Entity Framework` `SQL` `Docker`
